# AIDA Eval Questions (ระยะ A + C1)

วิธีใช้: ถาม AIDA ใน Copilot ทีละข้อ แล้วติ๊กผลในตารางท้ายไฟล์
Q1–Q21 = ระยะ A (คำปรึกษา) · Q22–Q32 = ข้อมูล E โอนเงิน (ปรับจาก B1 ให้ใช้ engine) · Q33–Q47 = ระยะ C1 (Intake Review, ข้อมูล C / A, โหมดสำรวจ, mapping profile)
ข้อที่วิเคราะห์ข้อมูล: เปิดแชตใหม่ทุกข้อ ยกเว้นที่ระบุว่าต่อจากข้อก่อน; โหลด engine ตาม AIDA-16 ก่อน (แนบ `5-engine/aida_engine.py` + `AIDA-14-configuration-registry.md` หรือลิงก์ SharePoint) และใช้ไฟล์ใน `4-samples/` ของ zip (ใน repo คือ `samples/`)
ผ่าน = มีครบทุกข้อใน "ต้องมี" และไม่มีข้อใดใน "ต้องไม่มี"
